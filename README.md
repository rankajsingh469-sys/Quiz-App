# Quiz Website

A simple interactive quiz website built with **HTML, CSS, and JavaScript**.

## Features

* Multiple-choice questions
* Instant correct/incorrect feedback
* Score tracking
* Dynamic question and option generation
* Options disabled after selection

## Technologies

* HTML5
* CSS3 / Tailwind CSS
* JavaScript

## Project Structure

```text
quiz-website/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

Open `index.html` in your browser or use **VS Code Live Server**.

## Purpose

This project was created to practice **JavaScript DOM manipulation, events, arrays, objects, and basic quiz logic**.
